# Dynamic Resume Builder

A web-based application built with PHP and MySQL that allows users to create and download professional resumes with customizable templates.

## Features
- Real-time resume preview
- PDF generation
- Customizable templates
- User-friendly interface

## Technologies Used
- PHP
- MySQL
- HTML/CSS/JavaScript

## How to Run
1. Import `database.sql` to your local MySQL server
2. Set your DB credentials in `config.php`
3. Run using XAMPP/LAMP server
